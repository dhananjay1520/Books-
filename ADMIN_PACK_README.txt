BookSpot Admin — Booksto-inspired UI pack
==========================================

This ZIP contains only admin-specific files from the BookSpot CodeIgniter 3 project.
The design is an original implementation inspired by the clean bookstore/admin-dashboard ideas visible in the referenced Booksto template: compact KPI cards, simple charts, category summaries, quick actions, responsive navigation, and bookstore-focused management screens.

Use:
1. Backup your current project.
2. Extract the ZIP in your BookSpot project root and overwrite matching files.
3. Keep the rest of the application/system/assets files from your existing project.

Important:
- No ThemeForest/Booksto source files are included.
- The pack does not include the commercial template.
- The existing BookSpot routes, database logic, cart, checkout, rent, profile, and storefront remain outside this admin-only pack.
