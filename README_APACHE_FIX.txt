BOOKSPOT XAMPP INSTALL

Put this folder under C:\xampp\htdocs\book\ and make sure:
book\index.php
book\application\
book\system\
book\assets\

Open http://localhost/book/

Do NOT put application.zip contents directly into C:\xampp\htdocs\book\application as the entire site.
If Apache still shows Forbidden, verify httpd.conf allows access to C:/xampp/htdocs and restart Apache.
